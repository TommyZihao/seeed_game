# 矽了个递

同济子豪兄制作的 Three.js 三维产品三消游戏。支持闯关、乱炖、英伟达/高擎动力/矽递科技/LeRobot 专区、产品图鉴，以及语音复活。

## 本地启动

需要 Node.js 22 或更新版本。

```bash
npm ci
npm run serve
```

浏览器打开 http://localhost:8081 。加载完成后点击“进入游戏”，进入首页并启动音乐。浏览器须启用 WebGL 2 和图形加速。

## 语音复活

复制 `.env.example` 为 `.env`，填写自己的阿里云百炼配置。密钥仅由 `server.mjs` 在服务端读取，请勿提交到 GitHub。详见 [语音配置](阿里云语音配置.md)。未配置时，基础游戏仍可运行。公网麦克风录音需要 HTTPS。

## 离线文件

```bash
node scripts/build-offline.mjs
```

生成 `抓个矽递-3D.html`，包含模型、图片与音乐。此文件体积较大，不纳入仓库；直接打开离线文件时不支持服务端语音复活。

## 项目文件

- `game.js`：玩法、物理模拟、关卡和图鉴。
- `home-stage.js`：首页互动机器人展台。
- `assets/models`：游戏所需 GLB 模型。
- `assets/model-sources`：模型来源记录。
- `scripts`：资源处理、离线打包和验证脚本；部分资源处理脚本需要另外取得原始 CAD 文件。

原始 CAD、虚拟环境、依赖目录、本地密钥及部署临时文件不包含在仓库中。第三方模型、音乐和品牌素材的来源说明不等同于再分发或商业授权。
